# WebDAV 同步设置原型

这是规格实施第二阶段的临时评审应用。它复用项目现有的 Vue、Vite、Element Plus、图标和视觉变量，不调用扩展 API，也不会连接或修改任何 WebDAV 服务器。

## 启动

```bash
pnpm prototype:webdav
```

默认访问 `http://127.0.0.1:5173/`。构建检查使用：

```bash
pnpm prototype:webdav:build
```

## 评审内容

- 顶级独立“WebDAV 同步”设置分类，和“其他设置”并列。
- 首次向导：连接、精确权限、只读扫描、范围、壁纸、三方比较和最终确认。
- 同步状态、动态 `cloud-off`、逐项冲突、历史、设备、损坏修复、加密、壁纸压缩和危险操作。
- 未配置、已有库、自动合并、冲突、等待权限、壁纸超限、507、损坏、格式过新和加密锁定等假数据场景。
- 桌面和窄屏布局。工具栏只用于评审，不会进入扩展。

## 边界

- 原型文案暂以简体中文评审。正式接入时再按规格同步更新英文、简体中文、繁体中文和香港繁体资源。
- 当前按钮只改变假 Adapter 状态或显示提示，不执行网络、存储、权限和删除操作。
- 原型确认前不会把页面接入生产设置路由；确认并获准接入后，原型将在生产 UI 验收完成时删除。
