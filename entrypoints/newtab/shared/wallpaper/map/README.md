# 奇幻地图壁纸

地图采用羊皮纸与手绘墨线风格，地图几何和矢量符号均由本模块生成。

- `terrain.ts`：固定世界坐标的单侧或相邻双侧海洋、自然导航水域、独立湖泊、远海小岛、高度与山脊；动画使用连续的岸线距离场，避免地形查询边界进入过渡轮廓。
- `coast.ts`：连续海陆场的岸线和水面轮廓。
- `coastAnimation.ts`：首屏从全陆地展开海岸。复用现有动态壁纸的场快照和纹理工具；仅在过渡期间绘制透明岸线叠层，逐步淡出并显示底层静态岸线。大幅扩展窗口时直接使用最终岸线，避免新旧地图之间的直线分界。
- `generate.ts`：优先洪泛排水、聚落与港口选址、连通道路/铁路、桥梁和标签避让。
- `rivers.ts`：共享下游曲线与汇流切线、沿程增宽、河口及湖泊出口的精确岸线裁切。湖泊出口直接从较宽的河道开始。
- `spatial.ts`：河流/交通线段的空间索引，供桥梁和装饰避让使用。
- `ports.ts`：搜索水面方向和码头跨度，保证木板两侧留在水中。
- `annotations.ts`：地名与罗盘的矢量绘制，保持原生分辨率。
- `paper.ts`、`paint.ts`：缓存纸张纹理、静态地图绘制、山体前后遮挡，以及独立的船、火车、海浪和旗帜动画。
- `map.worker.ts`：在 Worker 中生成并绘制静态地图，通过可转移位图提交结果；保留上一版数据以复用未受影响的河道和交通路线。
- `mapScene.ts`：合并待处理请求、丢弃过期结果、管理位图/画布及动态局部清除；窗口变化只裁切或扩展，不缩放世界对象。

中央水域覆盖大部分导航背后，允许边缘图标位于岸上。导航、时钟、搜索框和罗盘周围减少细节；罗盘从不遮挡操作按钮的角落中选择，并在操作按钮位置变化时重新检查。港口通过陆路直连所属城镇，引桥连接仓库与水中码头；能铺设铁路时同时生成支线，狭窄陆桥则保留道路连接。

稳定对象的种子、聚落 ID 和名称在同一页面中保持不变。窗口扩大时复用仍然有效的河道和道路，补充新区域；导航水域覆盖旧路线时重新寻路。静态地图一次性提交，避免展示半条铁路。动画时间使用现有动态壁纸调度器，支持帧率上限和现有暂停选项。火车与船数量在绘制阶段控制，不触发地形重绘；岛屿数量改变时重新生成地形。船与火车的动画相位由路径身份决定，重绘不会从头播放。

静态地图仅在布局或岛屿数量变化时重绘。快速扩大窗口时，Worker 先补齐低分辨率的真实海陆形状，随后生成完整地图；首屏先显示羊皮纸底色，再扩张海岸，并以不规则墨迹同时显现地物与地名。静态岸线位于山体和建筑下层，避免穿过其轮廓。水域内部使用合并扫描行，岸边保留精细多边形；常驻动画只清除上帧的小范围区域，不逐帧复制整张地图，画面外的海浪不参与绘制。原生地图渲染 DPR 上限为 1.5，海岸过渡上限为 1；拖动结束后收回过大的画布，切换 DPR 时按当前视口重新分配，避免长期保留最大窗口的显存开销。

运行拓扑与回归检查：

```sh
node --test scripts/tests/map.test.mjs
```

测试覆盖确定性、单双边海洋、导航水域形状、动画场连续性、交通连通和离岸距离、河口裁切、汇流切线及沿程增宽、港口连接和码头水域约束、罗盘净空、帆船水域约束、火车弯道采样、扩展窗口时的几何复用。真实扩展页面的视觉和生命周期验证按项目的 `extension-browser-debugging` Skill 进行。
