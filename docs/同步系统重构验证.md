# 同步系统重构验证

日期：2026-10-01。对应 [重构计划](同步系统重构计划.md)。

## 实现结果

- 设置投影以当前默认结构为准，共用本机与同步的类型、枚举、数值、颜色、搜索引擎顺序及关联设置规范。安全同步组内新增字段自动发现，旧字段从当前数据清理；缺失新增字段与显式用户编辑分别处理。
- 配置 10→11→12 复用原迁移函数，支持部分同步设置；完整本机迁移与同步共用纯迁移登记，本机存储迁移的副作用保留。
- revision、备份和工作记录保存来源版本；`pluginVersion` 来自运行扩展的 manifest。来源更新时先阻塞，升级后重新检查并恢复，避免旧客户端过滤新字段后回写。
- `snapshotCodec.ts` 统一迁移、投影、资源引用清理、校验及顺序规范化；原始历史内容和哈希不改写。当前 revision 和基线去除未知设置、类别、实体成员及未引用图标。
- 手动开关、范围和后台凭据偏好保留本机；全部关闭有效。停用类别保留最后有效比较基线，发布其他类别时保留最新远端内容，重新开启后进行三方比较。
- 操作身份、恢复日志、应用标记和本机写锁保留；状态更新、同步及远端维护读取串行。不可变 payload/commit 发布不依赖 ETag、条件 PUT 或 LOCK，响应不确定时查证已保存内容。
- 网络、超时及临时错误采用持久退避和浏览器 alarm；手动暂停停止执行。凭据失效、权限缺失及空间不足有保留连接和数据的恢复入口。
- 仅缓存已验证的当前结构工作副本，最多 8 个、合计 16 MiB；正常同步重新读取头版本，显式历史检查重新读取原始内容。
- 五种语言同步更新，纯回归接入构建 CI。
- 便签字段投影和 1 MiB/8 MiB 容量限制统一于 `shared/notes/model.ts`；本机读取和保存清理废弃成员，合并、导入和本机应用在落盘前检查，发布在上传任何资源前检查。超限保留原数据和基线，缩减数据后可重试。
- 恢复日志区分同步与手动导入：未提交同步计划尊重最新启用状态和范围，已提交数据仅完成恢复收尾；手动导入按备份内容作用于本机。启动恢复失败保留错误和日志，不阻断新标签页，无日志时不等待远端网络任务。
- 替换应用日志在同一 IndexedDB 事务中回收旧暂存壁纸和应用标记，安装新日志及资源；失败中止事务。便签初次加载不再重置等待期间创建的草稿。

实现中补修了真实回归暴露的问题：首次连接独立实体被误报冲突、没有可信基线时复活已删除便签、首次未启用图标后再启用无法下载、应用前后设置规范不同导致反复失败、设置创建/删除事件异常、含点号实体 ID 的字段冲突解析，以及同浏览器历史读取撞上清理。保留真实删除/修改分歧，由用户选择本机、远端或两份。

## 复跑

纯回归：

```powershell
node --test tests/webdav-schema-regression.test.mjs tests/webdav-write-regression.test.mjs tests/notes-regression.test.mjs tests/notes-save-regression.test.mjs tests/notes-backup-regression.test.mjs tests/notes-sync-boundaries.test.mjs
```

真实回归先运行 `pnpm build`，设置 `WEBDAV_TEST_URL`、`WEBDAV_TEST_USER`、`WEBDAV_TEST_PASSWORD`。Playwright 模块和系统 Chromium 路径可分别用 `PLAYWRIGHT_MODULE`、`PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定。使用支持直接读取 TypeScript 的 Node 运行：

```powershell
node tests/webdav-master-live.mjs
node tests/webdav-evolution-live.mjs
node tests/notes-sync-live.mjs
node tests/notes-save-ui.mjs
node tests/notes-ui.mjs
node tests/notes-preview-ui.mjs
```

本机因用户已有依赖清单与安装状态存在差异，验证时设置 `pnpm_config_verify_deps_before_run=false`，没有重新安装依赖或修改用户已有 `package.json`、`pnpm-lock.yaml` 改动。

本轮复查发现的问题均先用原路径产生失败，再用修复后的构建验证：暂停后打开新标签页重放旧便签、关闭类别仍应用旧计划、废弃便签成员造成持续发布、合法的 4 条与 6 条各 900 KiB 便签合并后超限、恢复失败阻断启动、同步关闭类别导致导入遗漏、导入中断无法启动恢复、替换日志遗留壁纸暂存文件，以及慢速初次加载覆盖刚创建的草稿。新增启动检查引入的网络等待也通过阻塞真实请求复现并修复。两个审查维度最终均无剩余阻塞项。

## 维护约束与验证边界

- 新增顶层设置组、类别或本机专用字段须明确同步/隐私归类；新增枚举、范围或字段语义须更新规则或配置迁移。代码无法自动推断隐私边界和改名对应关系。
- 正式发布版本严格递增；旧客户端遇到未来版本暂停写入。未提供实验同步格式的迁移。
- 已有历史保留原始未知字段和资源引用，使用时转换，之后按现有保留策略回收；本轮没有批量改写历史。
- 两浏览器同时写同库按用户前提排除；同浏览器多页面、重叠触发与维护读取已覆盖。
- Firefox 完成构建，未执行真实 Firefox 扩展运行测试；未逐一验证其他 WebDAV 产品或原生权限弹窗，也未进行长期、大规模压力测试。

确认前提和本轮覆盖范围内，已发现的严重缺陷均有修复及通过的回归。测试结果不构成对所有未来发布、所有服务端实现和所有故障组合的无缺陷保证。
